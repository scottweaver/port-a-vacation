# v3.8 — Condo portal 🏠

One-tap access to the TrackHS guest portal from the dashboard.

## What's new

- **Condo Portal card** between the booked activities and the meal plan. Tap "Open portal" and you're logged into the TrackHS guest portal automatically — no email or password needed.
- The portal has the check-in code, wifi, house manual, contact info, and whatever else the host has posted there. One link instead of digging through emails.
- Card defaults to expanded so the button is visible, but you can collapse it like every other card on the dashboard.

## Under the hood

- New `CondoPortalCard.tsx` reads the portal URL from `VITE_CONDO_PORTAL_URL`. The link is a TrackHS auto-login bearer token — anyone holding it can hit the portal without credentials — so it lives in env vars (Vercel Production + local `.env.local`), not in committed source. The public GitHub repo never sees the link.
- When the env var is unset, the card renders a small "Portal link not configured" hint instead of the button. Safe fallback so prod doesn't crash if the var is ever missing.
- Card is inside the `!filterActive` block so it auto-hides under search like the other planning cards.
- No schema changes, no prod migration.
