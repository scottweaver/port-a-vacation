# v3.12.1 — Missing-first is family-scoped now

Patch on v3.12. The "missing first" sort treated quantity items globally — "missing" only if nobody at all had committed any. That's wrong: another family bringing 6 towels doesn't mean MY family doesn't still need to bring some. Now mirrors how tasks already worked.

## New semantic

- **Count items** → missing if **my family** hasn't committed any quantity (was: nobody had committed any). Family-scoped, same as tasks.
- **Task items** → unchanged. Missing if my family hasn't ticked it.
- **Claim items** → unchanged. Missing only if nobody has claimed it (single-provider; one family claiming covers everyone).

Fallback (rare): if the user has no family yet, count items fall back to the overall-coverage signal.

## Under the hood

- One-line change in `isMissing()` inside `ChecklistSection`. Comment block updated to reflect the family-scoped reading.
