# v3.15.1 — License auto-detection fix

Patch on v3.15. The LICENSE file had a dual-license header pasted above the canonical AGPL-3.0 text. GitHub's [Licensee](https://github.com/licensee/licensee) detector — the algorithm that decides which license badge to show in the repo sidebar — requires the file to be unmodified canonical license text. The header was throwing it off, so the repo showed "Other" instead of "AGPL-3.0".

## Fix

- **`LICENSE`** — now pure canonical AGPL-3.0-or-later text. Licensee should auto-detect on the next index pass (usually a few minutes after push).
- **`NOTICE`** (new) — contains the dual-license header content that used to be on top of LICENSE. Standard convention for projects that want license-detection + extra copyright/licensing notes.
- **README.md** — project structure updated to mention NOTICE alongside LICENSE.

No code change. No effect on legal scope — the copyright notice and dual-license declaration are preserved verbatim, just in the conventional file location.
