# v3.10 — On-island essentials 🧭

New "On-Island Essentials" card under the meal plan. Lists the stuff you can grab without taking the ferry back to the mainland — for those "we're out of ice" / "kid needs allergy meds" / "need bait by 6am" moments.

## What's new

- 🛒 **Lowe's Market** — the only grocery on the island (used to be Family Center IGA; same building, new owners as of 2025).
- 🔧 **Ace Hardware** — beach gear, propane, paint, key cutting, glass cutting.
- ⛽ **Valero (SH-361)** — on-island gas. Also sells the city's $12 beach parking permit.
- 🐟 **Island Tackle** — bait, tackle, rod + reel rental & repair.
- 💊 **CVS Pharmacy** — prescriptions, immunizations, sundries, drive-thru.
- 🍺 **Spanky's Liquor** — beer, wine, liquor on the central Alister drag.
- ☕ **Coffee Waves** — iconic local. Espresso, gelato, indie bookstore inside.

Each entry has tap-to-call phone and tap-to-Google-Maps address. Hours included where known.

## Under the hood

- New `ON_ISLAND_ESSENTIALS` array + `OnIslandEssential` interface in `trip-data.ts`, mirroring the existing `RESTAURANTS` / `ACTIVITIES` shape. Static data (not DB-backed) — the list of grocery/hardware/bait shops doesn't change much, so deploy-to-update is fine. If the list grows beyond what's worth deploying, easy enough to move to a `condo_info`-style admin-editable table later.
- New `OnIslandCard` component rendered between MealsCard and the checklists. Grouped by category for future-proofing (right now each category has one entry, but if a category gains a second the rendering already clusters them).
- No schema change, no migration. Card is inside the `!filterActive` block so it auto-hides under search like the other planning cards.
