# v3.7 — Live weather + tides 🌤️🌊

The Weather and Tide cards used to show hardcoded best-guess data from when the app was first written. Now they pull live data from real sources.

## What's new

- **Live weather forecast** for May 25–29 in Port Aransas, pulled from [Open-Meteo](https://open-meteo.com). Auto-refreshes when you reopen the app or reconnect from offline.
- **Live tide predictions** from the [NOAA CO-OPS](https://api.tidesandcurrents.noaa.gov) station at Port Aransas (8775237). Same auto-refresh behavior.
- **Freshness badge** next to each card title shows "Updated 4m ago · Open-Meteo" (or NOAA) plus a refresh button you can tap to fetch fresh data on demand.
- **Graceful fallback** — if the API is unreachable (offline, service down), the cards fall back to the baked-in estimates the app shipped with, and a coral indicator says "Showing baked-in estimates · Open-Meteo unreachable" so you know what you're looking at. The app keeps working through any network hiccup.

## Under the hood

- Two new helper libs: `src/lib/openMeteo.ts` and `src/lib/noaaTides.ts`. Pure fetch + parse functions, no React dependencies. Parsers covered by 17 new unit tests (85 total now).
- WMO weather codes → our 5-bucket Condition: 0=sunny, 1-2=partly-cloudy, 3=cloudy, 45/48=fog→cloudy, 51-57=drizzle, 61-67/80-82=rain, 95-99=thunderstorms→rain. Defensive fallback to partly-cloudy for unknown codes.
- NOAA "hi/lo" interval gives ~4 predictions/day. Grouped by date, hi/lo split, times formatted to 12-hour. New "Best Time" heuristic: morning low → "Morning shelling near 6:12 AM", afternoon low → "Afternoon shelling at 1:08 PM", fallback to "Swim near high tide at …".
- New hooks `useWeather` + `useTides` use stale-while-revalidate: hydrate from localStorage cache on first render, fetch in background, refetch on reconnect and on tab-focus when cache is older than 1 hour. AbortController cancels in-flight fetches if you trigger another before the first resolves.
- New `FreshnessBadge` component shared by both cards. `e.stopPropagation()` on the refresh button so it doesn't trigger the parent CollapsibleCard's toggle (same pattern as the existing unread-count pills).
- No schema changes, no prod migration. Both APIs are free, keyless, and CORS-permissive.
