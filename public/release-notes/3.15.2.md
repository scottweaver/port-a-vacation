# v3.15.2 — Dropped 🏖️ from browser tab title

Small visual fix. The `<title>` was `Port A 2026 🏖️` — browsers render emojis in tab titles as colored graphics, so you saw the beach umbrella twice: once as the favicon on the left of the tab, once as an emoji at the end of the title (often cut off when the tab gets narrow). v3.14's `(N)` unread-count prefix made the title longer and pushed the trailing emoji into the cutoff zone more often.

Fix: drop the emoji from `<title>`. The favicon (which IS the 🏖️) already carries the visual identity, no need to repeat it. The in-app header — the big "Port A 2026 🏖️" inside the dusk-gradient banner — keeps the emoji; that's an explicit styled element, not a tab-strip glyph.

No code change beyond `index.html`. The `useTabBadge` hook keeps working since it looks for the base title at runtime — `(3) Port A 2026` instead of `(3) Port A 2026 🏖️`.
