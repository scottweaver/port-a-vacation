# v3.3 — Gulf coast vibes

A whole-app visual pass. Everything still works the same — but now it actually feels like a trip to the Texas coast.

## What's new

- **New header** — the cool ocean→teal banner is gone. In its place: a Gulf-sunset gradient (deep dusk purple → coral → gold) running diagonally across the top, with a tropical palm-and-sun vector illustration anchoring the corner. The island silhouette rests right against the bottom of the search section.
- **"Port A 2026" in script** — the title is now set in Caveat, a casual handwritten font that feels like a postcard from the beach. Subtitle text rebalanced to warm cream tones.
- **Ocean search bar** — the search section underneath the title now has a dusk-to-deep-ocean gradient, so the palm island visually sits "in the water." The search input itself has a warm cream background with a pale-gold border, so it harmonizes with the cards below.
- **Warm cards** — every dashboard card (Weather, Tide, Drive, Booked activities, Checklists, Places, Info) switched from cool corporate white to warm sand cream. The existing sand→ocean page background now flows naturally into the cards instead of fighting them.
- **Per-category color stripes** — each checklist section (Beach, Clothing, Kitchen, etc.) now has its own thin colored awning at the top of its card, with a soft matching glow cast down into the card body. Beach gets ocean blue, Clothing gets coral, Kitchen gets sage green, Games gets lavender, and so on — restraint-first palette, one color per category. The tint also gets brighter when you expand the card, dims when you collapse it.

## Under the hood

- Palm tree decoration is now a real vector asset (`public/palm-sunset.svg`) rather than a hand-coded SVG approximation. Positioned to anchor at the bottom of the full sticky header (gradient + search + update banner together), with z-index tuned so the title text floats above and search controls remain interactive through it (`pointer-events-none`).
- New Tailwind tokens: `dusk-{600..900}` (deep sunset sky indigos), `sunset-{300..600}` (gold → rose horizon), `sage-400`, and `lavender-400` for the muted herb/play category accents.
- `CollapsibleCard` gained `tint` / `tintFade` / `tintShadow` props so any card can opt into the per-category awning treatment. The `tintFade` element transitions opacity smoothly between collapsed (50%) and expanded (100%) states.
- Theme-color meta swapped from ocean-blue `#0284c7` to dusk `#2d1b4e` so iOS Safari's status-bar tint matches the new identity.
- Caveat font is loaded from Google Fonts with `preconnect` + `display=swap` so it doesn't block first paint.
- No schema changes, no behavior changes — everything that worked yesterday still works the same way. Only the visual layer changed.
