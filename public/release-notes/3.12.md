# v3.12 — Per-category sort 🔀

Each checklist section now has a small **Sort** picker in its body (just above the items list). Three modes:

## What's new

- **Default** — the original curator-order (sort by `sort_order`), unchanged from before.
- **A–Z** — sort by item name, case-insensitive locale-aware.
- **Missing first** — items still needing attention float to the top; covered ones sink to the bottom. Within each group, fall back to default order.

The picker is hidden when a category has 0 or 1 items (nothing to sort). Choice is per-user, per-category, persisted to localStorage (same pattern as the collapsed-state preferences) — so each family member sees their own sort, and it survives reloads on the same device.

## What "missing" means per item type

- **Count items** (sunscreen, beach towels) — missing if **nobody** has committed any quantity yet (total = 0 across all families). Once anyone bumps the count above zero, it's no longer missing.
- **Task items** (lock door, check windshield) — missing if **my family** hasn't ticked it. Tasks are per-family, so another family's tick doesn't help yours close out.
- **Claim items** ("someone bring a beach umbrella") — missing only if **nobody** has claimed it. Once any family claims it, the item is covered for everyone — including the families not bringing it (which was the user-requested rule: claim items don't show as missing for families NOT bringing them).

## Under the hood

- New `useSortMode` hook (`src/lib/useSortMode.ts`) — mirrors the `useCollapsedState` pattern (`port-a:sort:<userId>:<categoryKey>`). Falls back to `'default'` if localStorage is unavailable or holds an unknown value.
- New `isMissing()` helper inside `ChecklistSection` switches on `tracking_type` to produce the right semantic.
- Sorted list is a `useMemo` over `[visibleItems, sortMode, families, myFamilyId, getContribution]`. Default mode is a passthrough (no copy) so the common case stays cheap. Hidden items live in their own subsection and are not affected by sort.
- No schema change, no migration.
