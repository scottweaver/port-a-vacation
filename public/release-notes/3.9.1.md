# v3.9.1 — Hide-by-default codes 👁️

Small UX patch on top of v3.9. The door code, pool code, and wifi password on the Condo card now start masked — tap the eye icon to reveal, tap again to hide. Helps when someone's looking over your shoulder.

## What's new

- 👁️ **Reveal/hide toggle** on the two code tiles (door, pool) and on the wifi password row. Hidden state is the default on every page load — no "this stays revealed forever after I tap once."
- The value is replaced with `••••` characters while hidden — same length as the real value (door codes are usually 4–6 digits, wifi passwords usually longer), but no actual digits leak.

## Under the hood

- `CodeTile` gets an optional `secret` prop; the wifi password uses a new inline `Secret` component with the same Eye/EyeOff toggle pattern. Per-tile local `useState`, so revealing one doesn't reveal the others.
- `select-all` on the value spans so a triple-click still copies the real value when revealed (useful when handing the wifi password to someone's phone).
- No schema change, no migration.
