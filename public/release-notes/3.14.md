# v3.14 — Tab title shows unread count 🔔

When there are unread messages in any thread, your browser tab title now prefixes with a count: **(3) Port A 2026 🏖️**. Useful when the tab is backgrounded and the in-app badges aren't visible — flipping back to the browser shows the unread count right in the tab strip.

## What's new

- Browser tab title prefixes with `(N)` whenever your total unread message count is > 0.
- Capped at `99+` so the title doesn't get unwieldy.
- Drops back to the plain title the moment your unread count hits zero or you sign out.

## Under the hood

- New `useTabBadge(count)` hook in `src/lib/useTabBadge.ts` — pure DOM-side, strips any existing `(N)` prefix before applying the new one so successive count changes don't accumulate. Restores the base title on unmount.
- Wired into `Dashboard.tsx` next to the existing `totalUnread` `useMemo`. One line at the call site.
- No schema change. No new dependencies. Favicon-badge support (a red dot over the icon) is a possible follow-up — useful for mobile where tab titles are mostly invisible.
