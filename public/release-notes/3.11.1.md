# v3.11.1 — Shop badge counts what's still to buy

Patch on v3.11. The amber count badge on the Shop button was showing the total list size, including items already moved to "Got it." Now it only shows the count of items still in "Need to buy" — and disappears entirely once everything's been checked off.

## Under the hood

- Dashboard passes `shoppingPendingCount` (`entries.values().filter(p => !p).length`) instead of total `entries.size`. TopBar renames the prop and adjusts the tooltip ("N items still to buy" vs the old "N items").
- No schema change, no migration.
